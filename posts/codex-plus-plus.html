Codex++ 的教程｜Codex增强版下载与使用指南

codex客户端下载 https://codexdown.cn/

我为什么开始找 Codex 增强工具

最近一直在用 Codex 桌面端 写代码。 第一次打开时界面很干净、体验也不错，但真正长期使用后，一些细节问题开始明显：

  • 想删除测试会话 → 找不到删除按钮+ API Key 登录 → 插件入口直接灰掉+ 想自定义 API 路由 → 需要手改配置文件

这些问题单独看都不大，但日常使用会持续消耗耐心。

直到最近在 GitHub 看到一个项目： 👉 Codex++，一个专门给 Codex 桌面版做增强的开源工具。

体验之后，基本可以说：这才是更适合日常开发的 Codex。

一、Codex++ 下载地址

名称下载地址Codex++ 安装包https://pan.quark.cn/s/9fed9c3dfbeeGitHub 开源地址https://github.com/BigPizzaV3/CodexPlusPlus

支持平台：

  • Windows+ macOS Intel+ macOS Apple Silicon

二、Codex 官方版的真实痛点

先看官方 Codex App 存在的三个核心问题。

1️⃣ API Key 登录 → 插件入口被锁

使用 API key 登录时：

  • 插件按钮是灰色+ 点击提示必须登录 ChatGPT

这对很多开发者来说非常不方便。

2️⃣ 会话无法删除

官方只提供：

  • 归档+ 没有真正删除

项目一多，会话列表越来越乱。

3️⃣ API 路由不灵活

如果你想：

  • 使用兼容接口+ 切换中转 API

官方方案： 手动修改 ~/.codex/config.toml 并且可能被覆盖。

三、Codex++ 是如何增强 Codex 的

Codex++ 本质是一个 外部增强启动器。

技术方案非常干净：
项目技术后端Rust管理工具Tauri + React注入方式Chromium DevTools Protocol（CDP）

关键点：

  • 不修改 Codex 安装目录+ 不修改 app.asar+ 不写系统 DLL+ 仅在运行时注入增强脚本

这意味着：Codex 更新基本不受影响。

四、CDP 注入原理（核心理解）

Electron 本质 = Chromium + Node.js

CDP（Chrome DevTools Protocol）允许：

  • 调试浏览器+ 注入脚本+ 修改页面行为

Codex++ 工作流程：

  • 启动 Codex 并开启调试端口+ 连接 CDP+ 注入 renderer-inject.js+ 增强 UI 功能

可以理解为：

在应用运行时，动态给 Codex “装插件”

五、Codex++ 核心功能详解

1️⃣ 解锁插件 + 删除会话

增强后：

  • 插件入口恢复可用+ 会话列表悬停 → 出现删除按钮

这是最直观的体验提升。

2️⃣ Markdown 导出

支持将对话导出为 Markdown：

适合：

  • 知识整理+ 项目记录+ 技术笔记归档

3️⃣ Timeline 历史视图

类似版本回溯：

  • 查看会话历史状态+ 适合长上下文任务

4️⃣ 项目移动

支持：

  • 在 Codex 内移动项目目录+ 无需手改配置

5️⃣ 用户脚本系统

类似 Tampermonkey：

可以自定义脚本：

  • 改 UI+ 加功能+ 自动化操作

扩展空间非常大。

6️⃣ Provider 同步

切换 API 服务后：

  • 旧会话不会消失+ 登录态变化不影响历史记录

这是一个非常实用但容易被忽略的功能。

7️⃣ Zed 编辑器集成

支持：

  • 识别远程 SSH 环境+ 从 Codex 直接打开远程文件到 Zed

适合远程开发用户。

六、真正的杀手功能：中转注入

这是 Codex++ 最核心的能力。

使用场景

你已经：

  • 登录 ChatGPT 账号

但希望：

  • 模型请求走自定义 API

官方方案： 手改 config 文件 ❌

Codex++ 方案：

  • 检测登录态+ 添加 Base URL + Key+ 一键应用+ 从 Codex++ 启动

自动写入配置：

支持：

  • 多中转方案切换+ 一键恢复官方配置

对于经常切 API 的开发者非常友好。

八、项目技术架构

技术栈总结：

  • Rust：核心逻辑+ Tauri 2.x：管理工具+ React + Vite：前端+ NSIS：Windows 打包+ DMG：macOS 打包

技术选型偏实用主义。

九、总结

Codex++ 的本质：

把官方没做的”开发者刚需”补齐

解决的关键问题：

  • 插件解锁+ 会话删除+ API 中转+ Markdown 导出+ 用户脚本扩展

如果你正在使用 Codex 桌面端，这个增强工具几乎属于必装级别。
