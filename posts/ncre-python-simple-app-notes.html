计算机二级 Python 简单应用题（25 分）真题笔记（0101 ~ 1902 全套）

本文整理计算机二级 Python「简单应用题（25 分）」的常考题型与代码笔记。 编号说明：0101 表示第 1 套第 1 题，0302 表示第 3 套第 2 题，依此类推。 每套 2 题，共整理 19 套（0101 ~ 1902）。

第一套（0101 ~ 0102）

0101 四边形

考点：turtle.right(角度) 为相对当前方向转弯；turtle.fd(距离) 前进画线。四条边+四个转角凑成 360°。

0102

考点：while data: 配合末尾 data = input() 实现连续读入多行；int(ls[2]) 取年龄转整型累加；ls[1]=='男' 统计男性人数；最后求平均年龄并保留 2 位小数。

第二套（0201 ~ 0202）

0201

考点：turtle.seth() 设置绝对角度，left()/right() 是相对当前角度转弯；角度变量每次 +=90 实现旋转正方形。

0202（答案有问题）

考点：split() 按空格切分；d.get(键, 0) + 1 是字典计数万用写法；sort(key=lambda x:x[1], reverse=True) 按值降序排序。

第三套（0301 ~ 0302）

0301

考点：fd(-100) 表示倒退（原路返回）；seth((i+1)*90) 用循环变量算绝对角度。

0302

考点：与 0202 同一模板 —— 切分 → 字典计数 → list(d.items()) → 按值降序排序 → 逐项输出。

第四套（0401 ~ 0402）

0401

考点：import turtle as t 起别名；seth(i*120) 依次转 120° 画三角形。

0402（有问题）

考点：字典存「课程名→分数」；list(d.items()) + sort(key=..., reverse=True) 排序后，lt[0] 为最高分、lt[len(lt)-1]（即 lt[-1]）为最低分；sum(d.values())/len(d.values()) 求平均分。

第五套（0501 ~ 0502）

0501

考点：循环 8 次、每次转 45°，seth(d) 累计角度画八角星形。

0502（原文标注为 0520）

考点：readlines() 一次读入所有行；len(vote.split())==1 判断是否为单名有效票；vote[:-1] 去掉行尾换行符；D.get(键,0)+1 计票；reverse=True 按票数降序取 l[0]。

第六套（0601 ~ 0602）

0601

考点：5 次循环、每次转 72°（360/5）画正五边形。

0602

考点：两问分别为「统计有效票数」和「统计得票最多的名字」；name[:-1] 去换行；D.get(键,0)+1 计数；按票数降序取第一名。

第七套（0701 ~ 0702）

0701

考点：12 次循环、每次转 30°（360/12）画正十二边形。

0702

考点：两列表对应元素相乘再累加（向量内积）；注意累加语句写法 s = ls[i]*lt[i] + s。

第八套（0801 ~ 0802）

0801 棺材题画圆

考点：先画边长 200 的正方形，再转 -45° 让海龟朝向正方形顶点方向，用 100*pow(2,0.5)（100×√2 即正方形对角线的一半）画外接圆。

0802

考点：while True + break 做输入校验；"0" <= p <= "9" 判断字符是否为数字。

第九套（0901 ~ 0902）

0901 柱状图

考点：penup()/goto()/pendown() 组合实现抬笔移动；seth(90) 让画笔朝上；柱子底部 x 坐标按 x0 + (i+1)*50 依次排开；t.done() 保持窗口。

0902（有点难度）

考点：if name in pdict 判断字典键是否存在；pdict.get(name)[0] 取出列表中的手机号；random.randint(1000,9999) 生成 4 位随机数。

第十套（1001 ~ 1002）

1001

考点：r.choice(列表) 随机取色；r.randint() 随机半径与坐标；penup → goto → pendown → circle 是随机画圆的标准四步。

1002

考点：滑动窗口卷积（一维），range(len(img)-2) 控制窗口个数，k += filter[j]*img[i+j] 累加；{:<10.3f} 左对齐、宽 10、保留 3 位小数。

第十一套（1101 ~ 1102）

1101 小花

考点：for i in range(len(points)) 遍历坐标列表，x0,y0 = points[i] 解包；forward + backward 画出从中心点向外辐射的短线；360/angles 求相邻射线夹角。

1102（有点难 01）

考点：line.strip().split(',') 逐行清洗切分；dic.get(键, [])+[值] 向字典中的列表追加元素；sort(key=lambda x:len(x[1]), reverse=True) 按列表长度降序。 ⚠️ 原文最后一行末尾多了一个中文引号 ‘，实际运行需去掉。

第十二套（1201 ~ 1202）

1201 三个正方形

考点：setheading(90*(j+1)) 用循环变量设置绝对朝向画正方形；外层控制图形个数、内层控制边数。

1202（有点难度）

考点：with open(...) as f 自动关闭文件；eval(i[1]) 把字符串数字转数值累加；字典改列表后按占比降序，取前 3 名。

第十三套（1301 ~ 1302）

1301 靶场（有点特殊）

考点：画同心圆需把画笔移到 (0, -rs[i])（圆的最低点）作为起点；颜色与半径都从列表中按下标取。

1302（有点难度）

考点：jieba.lcut(s) 分词并用 if i in ",。" 过滤标点；第二段按字符遍历，用 word 拼接成句、遇标点用 {:^20} 居中输出。

第十四套（1401 ~ 1402）

1401 四个正方形

考点：外层循环画 n 个正方形；每个画完抬笔 fd(80) 移动到下一个起点（边长 40 不够，间隔要比边长大）。

1402

考点：while flag>0 限制最多 3 次循环；name in persons 判断名字是否在列表中；输入 q 提前 break 退出。

第十五套（1501 ~ 1502）

1501 画五个圆圈

考点：color[r.randint(0,4)] 用随机下标取颜色；goto() 内直接写随机坐标表达式；circle() 参数为随机半径。

1502

考点：jieba.lcut() 分词后 len(i) >= 2 过滤单字；d1.get(i,0)+1 统计词频；f.write() 写文件（写数字要用 str() 转换）。

第十六套（1601 ~ 1602）

1601 4 个交叉正方形

考点：color[r.randint(0,3)] 随机取色；随机位置起笔；内层 seth(90*i) 画正方形（i 取 1~4）。

1602（有点难）

考点：遍历标点字符串用 s.replace(i,"") 循环删除标点；jieba.lcut() 分词后 len() 得词语数。

第十七套（1701 ~ 1702）

1701 日本国旗（有点难）

考点：t.color('画笔色', '填充色') 双参数写法；begin_fill() / end_fill() 成对使用填充颜色；t.pensize(5) 在填充前设置粗细。

1702（有点难）

考点：with open(..., encoding="utf-8") 读文件、f.read() 一次读完；循环 replace 去标点；jieba.lcut(x, cut_all=False) 精确模式；sorted(..., key=lambda x:x[1], reverse=True) 按词频降序；result[:5] 取前 5。

第十八套（1801 ~ 1802）

1801 4 条头发（有点难）

考点：自定义函数封装绘图，t.circle(半径, 圆心角) 只画圆弧；circle(r, a) 与 circle(-r, a) 交替形成 S 形；函数内用全局变量 length、radius。

1802（有点难）

考点：两次文件读取 + 字典合并（键为学号），ds[学号] += [新信息] 追加；','.join(i[1]) 用逗号连接列表；fo.write('{},{};\n'.format(...)) 写回文件；三个文件对象都要 close()。

第十九套（1901 ~ 1902）

1901 五个正五边形（有点难）

考点：t.circle(半径, steps=n) 用 steps 参数直接画正 n 边形（本题 steps=5 画正五边形）；用 -200+i*70 让图形横向排开。

1902（有点难）

考点：自定义函数 + 循环调用；calpi(i+1, (i+1)*DART) 用循环变量计算结果作实参；{:2}、{:12} 为定宽格式化输出。

总结 · 高频考点速查

考点关键写法turtle 画图fd()、seth()/setheading()、circle(半径, steps=n)、circle(r, 角度)turtle 定点penup() → goto(x, y) / goto(x0,-rs[i]) → pendown()turtle 填充color('画笔色','填充色') + begin_fill() / end_fill()turtle 别名import turtle as t随机数random.seed()、randint(a,b)、choice(列表)、import random as r字典计数d[x] = d.get(x, 0) + 1字典分组dic[k] = dic.get(k, []) + [v]字典排序ls = list(d.items()) + sort(key=lambda x:x[1], reverse=True)字典转列表list(d.items())、d.keys()、d.values()、sum(d.values())/len(d.values())文件读open(f, 'r', encoding='utf-8')、readlines()、readline()、f.read()、with open(...) as f文件写open(f, 'w')、f.write('{},{};\n'.format(...))、f.close()字符串split()、strip()、replace(a,'')、join()、[:-1]、切片中文分词jieba.lcut(s)、jieba.lcut(s, cut_all=False)格式化{:.2f}、{:.3f}、{:<10.3f}、{:>4}、{:^20}数值eval() 转数值、pow(a, b)、len(t)-2 滑动窗口
