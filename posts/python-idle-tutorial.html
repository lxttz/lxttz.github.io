一、启动IDLE

1.1 三种启动方式

方式一：开始菜单（Windows）
  • 点击"开始"菜单+ 找到 Python 3.x 文件夹+ 点击 IDLE (Python 3.x)

######方式二：搜索启动

-的 式Windows*：按 Win 键，输入 IDLE

  • 持memacOS**：按 Cmd + Space，输入 IDLE
方式三：命令行启动(Win + r --> 输入cmd --> 回车)

1.2 IDLE界面认识

启动后看到的是 Shell窗口（交互式解释器）：

界面元素：

  • 第1-2行：Python版本和系统信息+ >>>：主提示符，等待输入命令+ ...：次提示符，表示多行代码未完成(旧版本没有)

Shell是即时执行Python代码的环境：

  • 输入代码 → 立即执行 → 显示结果+ 适合测试代码片段、快速计算

3.3 编辑器常用功能

代码缩进

Python对缩进要求严格，IDLE提供智能缩进：
快捷键功能Ctrl + ]增加缩进Ctrl + [减少缩进Tab自动缩进

操作：

  • 选中多行代码+ 按 Ctrl+] 统一增加缩进
批量注释

快捷键功能Alt + 3注释选中代码Alt + 4取消注释

查找和替换

查找（Ctrl+F）：

  • 按 Ctrl + F+ 输入要查找的文本+ 点击"Find Next"

替换（Ctrl+H）：

  • 按 Ctrl + H+ 输入查找内容和替换内容+ 点击"Replace"或"Replace All"
跳转到指定行
  • 按 Alt + G+ 输入行号+ 回车跳转
语法检查
  • 按 Alt + X 检查语法错误+ IDLE会将光标定位到错误位置

按 Alt+X 后显示：SyntaxError: invalid syntax

六、常见问题

问题1：找不到Python命令

症状：命令行输入python提示"不是内部或外部命令"

解决：Python未添加到环境变量PATH

  • 重新安装Python时勾选"Add Python to PATH"+ 或手动添加到系统环境变量

问题2：中文乱码

解决：在文件开头添加编码声明

问题3：按F5无反应

原因：文件未保存或Shell正在运行其他程序

解决：

  • 先保存文件（Ctrl+S）+ 按Ctrl+F6重启Shell+ 再按F5运行

何时使用IDLE

✅ 适合：

  • Python初学者（前3-6个月）+ 快速测试代码片段+ 学习基础语法+ 编写小型脚本（<500行）

❌ 不适合：

  • 大型项目开发+ 需要版本控制（Git）+ Web开发+ 团队协作

进阶选择：

  • 通用开发 → VS Code+ 大型项目 → PyCharm+ 数据分析 → Jupyter Notebook

学习资源推荐

资源链接Python官方文档https://docs.python.org/zh-cn/3/**菜鸟教程**https://www.runoob.com/python3/**廖雪峰Python教程**https://www.liaoxuefeng.com/wiki/1016959663602400

🎯 总结

IDLE核心功能：

  • Shell交互模式：即时测试代码+ 编辑器：编写和运行完整程序+ 基础调试：查看变量、单步执行+ 语法高亮：自动着色提高可读性

快速上手步骤：

  • 启动IDLE（开始菜单或搜索）+ 在Shell中测试简单命令+ Ctrl+N打开编辑器编写程序+ Ctrl+S保存为.py文件+ F5运行查看结果

最重要的快捷键：

  • F5：运行程序+ Ctrl+S：保存文件+ Ctrl+N：新建文件+ Ctrl+F6：重启Shell
