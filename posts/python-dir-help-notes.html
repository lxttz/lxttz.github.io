Python笔记：dir() 和 help() 完整用法（适配Python二级 + IDLE实操）

一、dir () 函数：查询「有什么可用」

作用

查看对象身上所有的属性、方法（变量.后面能调用的全部内容），只返回名字清单，不解释功能。

通俗理解：dir 是目录清单，告诉你这个东西有哪些工具。

语法

✅ 可以查询的对象（举例）

1. 查询变量（最常用）
2. 直接查询数据类型

不用创建变量，直接查看这个类型自带全部方法

3. 查询导入的模块
4. 查询自定义函数 / 类

📌 dir 返回结果的两类名称（重点区分）

+
不带双下划线：日常写代码直接使用的方法 / 属性
例：split、append、keys、strip

+
**前后双下划线 ****__xxx__**：魔法方法，Python 底层自动调用，写代码基本不用手动调用，可以直接忽略。

实用过滤代码（只看可用方法，过滤魔法方法）

IDLE Shell 中逐行输入执行

⚠️ 注意事项

+
IDLE >>>交互式窗口，一次只能输入一行代码，不能一次性粘贴多行，否则报语法错误。

+
dir不能查询关键字（if、for、while 等循环判断关键字），关键字要用help()查询。

二、help () 函数：查询「怎么用」

作用

查看对象、方法、模块、关键字的详细文档：功能说明、参数、示例。

通俗理解：help 是说明书，看懂工具怎么使用。

语法

✅ 常用示例

1. 查询对象的某个具体方法（最常用！搭配 dir 使用）
2. 查询内置函数
3. 查询整个类型的完整文档
4. 查询模块
5. 查询关键字（if、for、while 等语法）

⚠️ 注意事项

+
help 执行后会输出大量文字，按回车滚动查看，按q退出文档页面。

+
括号内如果写方法名不要加 ()，help(s.split) ✔，不要写成help(s.split())。

三、dir + help 配套工作流程（IDLE 标准查代码步骤，二级备考重点）

场景：不知道字符串怎么分割文字

+
在 Shell 定义变量：>>> s = "apple,banana,orange"

+
>>> dir(s) → 列出全部方法，找到目标名字 split

+
>>> help(s.split) → 阅读文档，看懂参数用法

+
测试代码：>>> s.split(",") 运行看结果

+
确认无误，把代码复制到.py脚本文件

四、dir 和 help 对比表

函数作用返回内容用途dir()查有哪些功能名称列表找方法名字help()查功能怎么用详细文档、参数看懂方法怎么调用

五、高频错题提醒

+
❌ 错误：help(s.split())
✅ 正确：help(s.split)

加括号代表执行函数，help 要传入方法本身，不是执行结果。

+
❌ Shell 一次性粘贴多行代码，触发multiple statements语法报错
✅ 正确：一行输入，回车，等待>>>提示符再输入下一行。

+
dir 不能直接看懂用法，只能看名字，必须配合 help。

六、背诵小口诀

dir 看目录，help 看说明；
dir 找名字，help 读详情；
双下划线，直接忽略掉。

随堂测试（你可以在 IDLE 直接试）
